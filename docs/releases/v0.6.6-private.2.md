# OmniRoute Private 0.6.6-private.2

Follow-up replacement package for 0.6.4-private.1. The earlier local
0.6.6-private.1 candidate is retained unmodified; this build must be used for
the host-registration repair.

## Fixed

- `repair-hosts` now repairs the package-owned OpenCode MCP entry along with
  Antigravity, Codex, and Claude Code. It resolves the active version at repair
  time, so updates and rollback do not retain an old source-checkout command.
- The extracted-package smoke test verifies and launches the exact registered
  OpenCode and Antigravity commands through MCP `initialize` and `tools/list`.
  It repeats those checks across upgrade, rollback, and a path containing spaces.
- The Antigravity launcher detects an immediate desktop-process exit and reports
  its status code rather than silently saying that the application opened.

The existing strict free-only provider policy, encrypted five-slot credential
storage, health/cooldown behavior, and browser-consumer limits remain unchanged.
No credentials, sessions, browser profiles, or customer prompts are packaged.

## Native Antigravity note

On the development machine, the official Antigravity executable currently exits
before its MCP server can start with Windows status `0x80000003`. This is an
official desktop-app native crash, not a missing OmniRoute Node executable or an
API-key error. The package preserves its installation and reports the failure;
repair or reinstall the official Antigravity desktop app before relying on it.

The archive is unsigned. Verify its adjacent SHA-256 file before installation.
