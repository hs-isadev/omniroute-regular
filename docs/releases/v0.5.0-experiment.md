# OmniRoute 0.5.0 experiment

This branch adds a local Claude web consumer to the verified 0.4.0 four-host
BYOK package. `main` intentionally remains the same package without this
consumer route.

The Windows and Linux installers retain OpenCode, Antigravity, Codex, Claude
Code, the graphical provider-key flow, and strict free-provider routing. They
also configure a fifth route, `claude-consumer/claude-web-consumer`, for small
text and coding requests.

The consumer uses a dedicated local browser profile and loopback-only debugging
port. It never bundles a login, cookie, key, normal browser profile, or personal
tab. Setup opens one visible login window; later desktop logins start only that
dedicated browser in the background. Windows prefers Opera GX. Linux supports
Opera, Chrome, or Chromium already installed by the user.

Claude receives the user's request text without system-role labels, rigid
formatting wrappers, or an injected `Be concise` preamble. This reduces false
prompt-injection-looking conversations without adding evasion text or wasting
prompt tokens.

Claude web quotas and account terms still apply. Browser automation can break
when the site UI changes, so OmniRoute marks this provider unhealthy and falls
back to another eligible BYOK worker when the connection is unavailable.
