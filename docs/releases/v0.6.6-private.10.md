# OmniRoute Private 0.6.6-private.10

This refresh packages the current verified Windows and Linux setup in a new,
immutable release archive. It explicitly documents the reusable
**OmniRoute API Keys** shortcut: Windows installs it on the Desktop and Start Menu, and Linux
installs it in the applications menu. Clicking it opens the same masked API-key window,
so users can add or replace keys later without running setup again.

The shareable package includes no API keys, browser sessions, cookies, or
personal data. The installer retains its existing key vault and configuration
on repair or upgrade. Check `VERIFICATION.md` for the package checks and
platform-specific limits before relying on the release.
