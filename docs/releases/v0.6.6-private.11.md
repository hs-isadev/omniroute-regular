# OmniRoute 0.6.6

This Windows/Linux package includes a repair for a stale browser-consumer
startup command left behind by older installations. Setup now recognizes the
known OmniRoute `.cmd` entry only when it contains the old version-pinned Node
and browser-adapter command, replaces it with the stable launcher, and removes
the obsolete entry. Unrecognized same-name startup commands are preserved.

The package also includes the **OmniRoute API Keys** shortcut and the current
host/MCP setup. It contains no API keys, browser sessions, cookies, passwords,
or personal data. See `README.md` for the plain-English installation guide and
`VERIFICATION.md` for package checks and platform limits.

The extracted archive passed its Windows family-package smoke: both OS
manifests verified, update/rollback and registered MCP handshakes passed, and
the OmniRoute protocol check used a fake provider. No live inference or native
Linux installation was performed.
