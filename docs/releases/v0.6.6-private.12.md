# OmniRoute 0.6.6

This Windows/Linux package fixes setup failures caused by an empty or truncated
OmniRoute or Antigravity JSON configuration file. Empty files are backed up and
replaced with safe defaults. Malformed non-empty files now produce an error that
names the affected file and preserves its contents for recovery.

The optional Devin CLI installer checksum warning remains non-fatal; it is
separate from OmniRoute setup. The package also includes the **OmniRoute API Keys**
shortcut and the current host/MCP setup. It contains no API keys, browser
sessions, cookies, passwords, or personal data. See `README.md` for the
plain-English installation guide and `VERIFICATION.md` for package checks and
platform limits.
