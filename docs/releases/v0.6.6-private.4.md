# OmniRoute Private 0.6.6-private.4

Follow-up replacement for `0.6.6-private.3`.

## Fixed

- The packaged OpenCode launcher starts with `--no-replay`, avoiding an unstable
  previous-session replay during automatic open.
- Antigravity registrations created by its official CLI may include `disabled:
  false`. The installer now recognizes only that exact enabled annotation on an
  otherwise verified OmniRoute-managed entry, so updates advance it to the
  installer-resolved active runtime. User-owned or deliberately disabled
  entries remain protected.
- Generated-package smoke tests cover the bundled Node executable, paths with
  spaces, update/rollback, and real MCP `initialize` plus `tools/list` for
  Antigravity and OpenCode.

No credentials, cookies, browser profiles, account sessions, or prompt history
are included in the package.
