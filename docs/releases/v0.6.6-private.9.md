# OmniRoute Private 0.6.6-private.9

Fixes Windows setup stopping when the official Devin CLI updater changes at its
stable download URL. The current updater's SHA-256 is pinned, existing cached
bytes are refreshed if they no longer match, and the official Authenticode
publisher check remains required before execution. Devin is optional: a failed
download, hash check, or signature check now warns and skips Devin without
blocking OmniRoute installation. An unverified updater is never run.

The Windows package smoke test exercises the bootstrap in an isolated temporary
profile with a mocked mismatched installer, verifies it is not executed, and
confirms the rest of bootstrap continues. It also checks the extracted package,
host registration, and MCP protocol using temporary homes and a fake provider.
