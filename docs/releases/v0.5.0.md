# OmniRoute 0.5.0

This release promotes the former browser-consumer experiment into the main
Windows and Linux package. It preserves the 0.4.0 BYOK providers, OpenCode,
Antigravity, Codex, Claude Code, graphical key setup, strict free-provider
routing, fallback behavior, and usage accounting.

One-click setup now also configures two local browser consumers:

- `claude-consumer/claude-web-consumer`
- `zai-consumer/glm-web-consumer`

Both are limited to small text and coding requests. They use separate dedicated
browser profiles and loopback-only debugging ports. Setup opens each profile for
a one-time user-controlled sign-in, then installs per-user background autostart
entries. Windows prefers Opera GX; Linux supports an installed Opera, Chrome,
or Chromium browser.

The archive contains no API keys, browser profiles, cookies, account sessions,
vaults, or personal projects. Browser-account quotas and terms still apply, and
UI automation may need maintenance when either site changes. A browser failure
is treated as a retryable provider outage so routing can continue through other
eligible workers.
