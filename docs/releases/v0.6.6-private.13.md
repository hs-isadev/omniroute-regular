# OmniRoute 0.6.6-private.13

The Windows Desktop and Start Menu **OmniRoute API Keys** shortcuts, and the
Linux applications-menu shortcut, now open the five-slot editor in existing
setup mode. Adding or replacing a valid slot preserves the user's current
routing configuration and other saved credentials. The five-slot editor is
included in both Windows and Linux download packages.

No credentials or browser sessions are included. Use the packaged SHA-256 file
to verify the sealed download before sharing or installing it.
