# OmniRoute 0.4.0

Four-host Windows/Linux release: standalone OpenCode as the main routed model,
plus Antigravity, Codex, and Claude Code as host agents with OmniRoute MCP
workers.

Highlights:

- One graphical bring-your-own-key flow with 12 strict-free/evaluation provider
  choices; saved secrets stay encrypted and are never packaged.
- Cerebras and SambaNova free-tier profiles with model allowlists and validation
  before activation.
- `omni_usage` and desktop usage launcher distinguish provider-reported token
  offload from unavailable counterfactual host-token savings.
- Idempotent Codex/Claude integration that preserves unrelated configuration and
  rejects ownership conflicts.
- Complete current compiled module overlays rather than stale baseline modules.
- Upstream MIT attribution retained; cookie/session/relay/anti-ban features
  excluded.

See the archive's `VERIFICATION.md` for platform tests and live-provider limits.
