# OmniRoute Dual 0.3.0

One download installs OmniRoute for both OpenCode and Google Antigravity on
Windows x64 or Linux x64 desktops.

## Install

1. Download the ZIP and checksum file below.
2. Verify SHA-256, then extract the entire ZIP.
3. Windows: double-click `Install-Windows.cmd`.
   Linux: run `sh Install-Linux.sh` in the extracted folder.
4. Use the graphical key window to obtain, paste, validate, and encrypt your
   own provider keys. One working provider is enough.
5. Complete the official Antigravity login when prompted.

SHA-256:

`eff44c7078e2dfd3712eda37403e507114557a9bd5eff311175fd96a44ad9cdb`

## Included

- OpenCode main-model routing with intent-based lightweight/strong selection.
- Antigravity MCP-worker integration.
- Same-provider free fallback before switching providers.
- Graphical masked key entry on Windows and Linux; no Notepad key workflow.
- Groq, Gemini, Cohere, Cloudflare, Mistral, OpenRouter, Kilo, Z.AI Flash,
  NVIDIA evaluation, and OpenCode Zen slots.
- Bundled pinned Node/OpenCode runtime and official Antigravity acquisition.
