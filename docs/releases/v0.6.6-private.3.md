# OmniRoute Private 0.6.6-private.3

Follow-up replacement package for 0.6.4-private.1 and
0.6.6-private.2.

## Fixed

- The package-owned OpenCode launcher now supplies `--no-replay` by default.
  It starts the isolated regular-mode/free-only configuration without replaying
  a prior OpenCode UI session that may be unstable. Explicit user launch
  arguments, including `--continue`, remain intact.
- The generated-package smoke test verifies the replay-safe launch arguments in
  addition to manifest integrity, update/rollback, and exact OpenCode and
  Antigravity MCP handshakes.

No provider credentials, sessions, browser profiles, prompts, or account data
are included. The free-only provider policy and browser-consumer limits are
unchanged. Verify the adjacent SHA-256 file before installation.
