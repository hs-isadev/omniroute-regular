# OmniRoute Private 0.6.6-private.5

Replacement candidate for `0.6.6-private.4`.

## Fixed

- `omni harness opencode --mode regular` now uses the authenticated local
  OmniRoute loopback gateway instead of requiring an OpenRouter key. It starts a
  temporary daemon only when the configured local daemon is unreachable, and it
  stops only that daemon when OpenCode exits.
- The generated OpenCode configuration pins `omniroute/regular`, disables replay
  and sharing, inherits no upstream provider credentials, and retains the
  free-only router's normal policy, health, cooldown, quota and capability gates.
- The Windows x64 installer adds an optional official Devin CLI flow. It verifies
  a fixed updater SHA-256 and `Exafunction, Inc.` Authenticode signature before
  execution, adds Desktop and Start-menu launchers, registers a local
  `omniroute_regular` MCP with the resolved active runtime, then opens the
  user-controlled Devin login.
- Package smoke coverage now includes a fixture Devin executable, active-version
  paths with spaces, and local regular-mode MCP registration arguments. It does
  not impersonate a Devin account or claim a live Devin result.

## Deliberate limits

Devin Fusion is a paid/metered Devin feature and remains disabled under this
release's strict free-only policy. The package never selects Fusion, enables paid
fallbacks, changes billing, imports Antigravity models, or represents Astra, Sol,
or Terra as available in Devin. Those models remain governed by the relevant
host/account entitlement.

Third-party “Fusion” repositories were considered only as untrusted reference
material. Their installers, prompts, dependency bootstraps, authentication code,
and global configuration changes were not run or copied. The implementation uses
only the official signed Devin updater and standard local stdio MCP registration.

No API keys, cookies, browser profiles, account sessions, vault contents, or
historical prompts are included in the package. Linux continues to leave Devin
unmodified; the optional verified installer is Windows x64 only.
