# OmniRoute 0.6.6-private.16

This package carries forward the safe five-slot key entry and provider-key
rotation behavior from .15. Existing keys are never overwritten by a new key;
duplicates are reported and skipped, and calls rotate across saved keys for the
same provider, including concurrent calls. Authentication failures move to the
next key and then follow the configured free-only provider failover policy.
The **OmniRoute API Keys** shortcut opens the same safe key editor for adding or
managing credentials after setup.

The OpenCode regular harness now tolerates slower daemon startup on Windows and
reports if the daemon process exits before becoming ready. The package checks
were also made portable across Windows and Linux.

Validation uses isolated fixture keys and stubbed transports. No live provider
credentials or live inference were used.
