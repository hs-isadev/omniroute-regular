# OmniRoute 0.6.6-private.14

The Windows Desktop and Start Menu **OmniRoute API Keys** shortcuts, and the
Linux applications-menu shortcut, open the five-slot editor in existing-setup
mode. Adding or replacing a valid key preserves the current routing setup and
other saved credentials. OmniRoute restarts after an accepted key change.

The smoke test now checks the packaged, minified shortcut route as it appears
in both downloadable payloads. No credentials or browser sessions are included.
