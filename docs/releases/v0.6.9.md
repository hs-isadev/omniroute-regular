# OmniRoute 0.6.9

Browser-consumer adapters have been removed from the source tree, provider
catalog, routing implementation, setup flows, and shareable package. This removes
the browser-driven Claude, Z.AI, Qwen, Kimi, DeepSeek, and Perplexity routes;
official API providers and native Claude Code host integration remain.

On upgrade, setup disables saved browser-consumer routes and removes only
recognized OmniRoute startup entries for those adapters. It preserves unrelated
startup entries and existing browser profiles/sign-in data, and does not close
already-running browsers.

The package remains the regular-mode Windows/Linux family distribution. Devin
CLI integration remains optional and locally configured; it is separate from
provider routing.
