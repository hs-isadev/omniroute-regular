# OmniRoute 0.5.1

Patch release for the Windows and Linux dual package.

- Starts the dedicated Claude and Z.AI browser setup processes concurrently.
- Waits for each one-time sign-in, then minimizes both browser windows while
  keeping their isolated profiles running in the background.
- Detects Chrome, Edge, Opera, Brave, Vivaldi and Chromium, with generic and
  per-provider executable overrides for other Chromium-family browsers.
- Handles Z.AI peak-hour notices by semantically selecting the visible
  `Switch to GLM 5.3 Flash` action. If it cannot do so safely, the route reports
  a retryable outage and OmniRoute falls back to the next eligible free provider.

Browser profiles, cookies, account sessions and API keys are excluded from the
download package.
