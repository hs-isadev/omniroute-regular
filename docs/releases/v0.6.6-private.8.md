# OmniRoute Private 0.6.6-private.8

This Windows/Linux package adds the GitHub package-release skill to the portable
skill bundle. It teaches a safe release workflow: prepare assets separately from
publishing, avoid pushing unrelated branch history, keep credentials out of
archives, and verify uploaded release files and checksums.

The skill is installed globally for Codex, OpenCode, and Antigravity by setup.
An existing same-named skill is preserved. No GitHub authentication token or
provider credential is bundled.
