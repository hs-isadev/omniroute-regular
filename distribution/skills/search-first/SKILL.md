## Workflow

1. Search the repository for an existing implementation, dependency, test, or documented pattern.
2. Check installed dependencies and the relevant official documentation when the behavior depends on a changing external API.
3. Prefer a suitable existing capability when it meets the need; otherwise explain the gap and add only what is necessary.
4. Keep exploration targeted and stop when the evidence is enough to choose an approach.

Do not turn a small, obvious edit into a broad research exercise or add a package solely because it is popular.
